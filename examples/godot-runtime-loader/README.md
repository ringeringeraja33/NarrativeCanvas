# Godot Runtime JSON Loader Example

This is a minimal Godot 4 integration sample for Narrative Canvas Runtime JSON exports. It uses plain GDScript and does not require a Godot plugin.

Files:

- `NarrativeCanvasRuntime.gd`: a reusable Runtime JSON session loader.
- `RuntimeRouteDemo.gd`: an optional Godot Node script that loads a Runtime JSON file plus route cases and prints route results.

## Setup

1. Copy both `.gd` files into a Godot 4 project, for example `res://addons/narrative_canvas_runtime/`.
2. Export a Runtime JSON file from Narrative Canvas, or use one generated by `scripts/portable-export-acceptance.cjs`.
3. Put the Runtime JSON and optional `routes.json` somewhere Godot can read, such as `res://narrative/`.
4. Attach `RuntimeRouteDemo.gd` to a Node and set:
   - `runtime_json_path`
   - `route_cases_path`

Example paths:

```gdscript
runtime_json_path = "res://narrative/state-runtime-key-play-runtime.json"
route_cases_path = "res://narrative/routes.json"
```

## Direct Usage

```gdscript
var runtime := NarrativeCanvasRuntime.from_file("res://narrative/story-runtime.json")
var page := runtime.current_page()
print(page["body"])

for choice in page["choices"]:
    print(choice["label"])

runtime.choose("opt_take_direct_route")
page = runtime.current_page()
print(page["body"])
```

## Covered Runtime Features

- Runtime JSON v1 loading
- initial variables
- node body and custom field template replacement
- `next`, `conditionBranches`, choice targets, and explicit routing targets
- `set`, `add`, `subtract`, `toggle`, `append`, `remove`, and `clear` effects
- bare keys, comparisons, `&&`, `||`, grouped expressions, `not`, `!`, `has(...)`, and `contains(...)`
- flat-first dotted key lookup, matching the portable export contract

This sample is intentionally small. In a production game, connect `current_page()` to your dialogue UI, save `runtime.get_state()` with the game save, and surface `report.warnings` from the export profile in your build pipeline.

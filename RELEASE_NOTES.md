# Narrative Canvas 1.1.2

Compared with GitHub release `1.1.1`.

## English

### Added

- Added a Playbook back-to-top button.

### Changed

- Play preview now opens as an embedded side panel inside the editor layout instead of a blocking modal dialog.
- Opening Play preview now switches to the canvas workspace, renders the selected runtime node, and centers the canvas on the active preview node as the route advances.
- The preview panel now has a fixed grid track, scrollable body, scrollable action footer, transparent backdrop, and responsive width handling.
- Playbook search now keeps focus in the search box after pressing Enter to jump through JSON matches.

## 中文

### 新增

- Playbook 新增“回顶部”按钮。

### 调整

- Play 预览从阻塞式模态弹窗改为编辑器布局内的嵌入式侧栏面板。
- 打开 Play 预览时会切到画布工作区，渲染当前运行节点，并在路线推进时把画布居中到当前预览节点。
- 预览面板现在使用固定网格列、可滚动正文、可滚动操作区、透明遮罩和响应式宽度处理。
- Playbook 搜索按 Enter 跳转 JSON 匹配项后，焦点会保留在搜索框内。
